    Lecture 2¶

    Robotics Primitives: Sense, Plan, Act, Learn¶

    Robots operate using a small set of core abilities.
    These are called the primitives of robotics.

    They describe how a robot interacts with the world and completes tasks.

    The four main primitives are:

    • Sense
    • Plan
    • Act
    • Learn

    Together, they form the basic intelligence loop of a robot.

    1) Sense¶

    Sensing is how a robot gathers information about the world.

    A robot uses sensors to detect: - distance
    - light
    - sound
    - position
    - obstacles
    - people

    Without sensing, a robot is blind to its environment.

    Example¶

    Environment → Sensors → Robot

    Example explanation:

    A robot vacuum uses: - distance sensors to detect walls
    - bump sensors to detect collisions
    - cameras or LIDAR to understand layout

    If sensing fails, the robot cannot make good decisions.

    2) Plan¶

    Planning is deciding what to do next based on sensed information.

    The robot: - interprets sensor data
    - chooses a goal
    - decides a sequence of actions

    Planning answers: "What should I do now?"

    Example¶

    Start → Path → Goal

    Example explanation:

    A delivery robot plans: - shortest path to destination
    - how to avoid obstacles
    - when to turn or stop

    Planning can be simple or very complex depending on the task.

    3) Act¶

    Acting is when the robot physically does something.

    Actions are executed through: - motors
    - wheels
    - arms
    - grippers

    Acting changes the real world.

    Example¶

    Decision → Motor Command → Movement

    Example explanation:

    A robot arm receives command: "Move to position X"

    Motors rotate → arm moves → object is picked.

    Without action, sensing and planning have no effect.

    4) Learn¶

    Learning allows a robot to improve over time.

    A learning robot: - remembers past experiences
    - adjusts behavior
    - improves performance

    Learning is common in AI-based robots.

    Example¶

    Example explanation:

    A robot vacuum learns: - which areas are usually dirty
    - which paths are faster
    - where obstacles often appear

    Over time, it becomes more efficient.

    Putting It Together¶

    A robot continuously loops:

    Sense → Plan → Act → (Learn) → Sense again

    This loop runs many times per second in real robots.

    Key Idea¶

    All robots, from simple to advanced, rely on these primitives.

    More advanced robots: - sense better
    - plan smarter
    - act more precisely
    - learn faster

    What is a Paradigm?¶

    Before learning different robot control styles,
    we must understand one important word:

    Paradigm.

    Definition¶

    A paradigm is a set of ideas, methods, and assumptions
    that guide how problems are understood and solved.

    It is like a "way of thinking" or a framework.

    A paradigm influences: - how we design systems
    - how we solve problems
    - what we believe is important

    When a paradigm changes,
    the way we build systems also changes.

    Simple Meaning¶

    A paradigm is: "How you think about a problem before solving it."

    Different paradigms lead to different solutions
    for the same problem.

    Example (Everyday Life)¶

    Write on board:

    Problem: Go to university

    Two people may use different paradigms:

    Person A: Plans full route → checks map → follows plan strictly

    Person B: Just starts walking → reacts to traffic and obstacles

    Both reach the destination,
    but their thinking style is different.

    These thinking styles are like paradigms.

    Science Example¶

    In science, paradigms change how we understand reality.

    Example:

    Newtonian Mechanics
    - World is predictable
    - Physics is deterministic

    Quantum Mechanics
    - World is probabilistic
    - Outcomes are uncertain

    Both explain the world,
    but in very different ways.

    When the paradigm changed,
    scientists built new models and tools.

    Robotics Connection¶

    In robotics, a paradigm decides:

    • How the robot thinks
    • How it makes decisions
    • How it uses sensor data
    • How it controls actions

    Different robotics paradigms lead to
    very different robot designs.

    Why Paradigms Matter in Robotics¶

    If you believe: "The robot must plan everything first"
    → you build a planning-heavy robot

    If you believe: "The robot should react instantly"
    → you build a reactive robot

    So the paradigm shapes the robot’s behavior.

    Key Idea¶

    A paradigm is not right or wrong.
    It is a design philosophy.

    Different paradigms work better
    for different situations.

    In the next parts,
    we will study major robotics paradigms.

    Hierarchical / Deliberative Paradigm¶

    Now that we understand what a paradigm is,
    the next question is:

    How should a robot make decisions?

    Should it: - think carefully first, then act?
    OR
    - act immediately based on sensors?

    Early robotics researchers believed:

    "A robot should think before acting."

    This idea led to the Hierarchical (Deliberative) Paradigm.

    Core Idea¶

    Think first, act later.

    The robot: 1) builds a model of the world
    2) plans what to do
    3) executes the plan

    Sense → Plan → Act

    Planning is the most important step.

    Why It Is Called Hierarchical¶

    It is hierarchical because decisions are layered:

    High level: - Goals
    - Missions
    - Long-term planning

    Low level: - Movements
    - Motor commands

    The top level controls the lower levels.

    World Model Concept¶

    The robot maintains a global world model.

    This is an internal map or representation of the environment.

    Example: - map of a building
    - positions of obstacles
    - known locations

    The robot thinks using this model
    before making a move.

    Example¶

    Sense → Build Map → Plan Path → Act

    Example explanation:

    A robot wants to go to an office.

    Step 1: It scans environment and builds a map.

    Step 2: It calculates the best route.

    Step 3: It moves according to the plan.

    It trusts its plan.

    STRIPS Idea (Simple View)¶

    Early planning systems assumed: - the world is predictable
    - the model is correct
    - nothing unexpected happens

    This is called a closed-world assumption.

    Meaning: "If it is not in the model, it does not exist."

    Strengths¶

    • Logical and structured
    • Good for known environments
    • Clear decision-making process
    • Works well when world is stable

    Limitations¶

    Real world is messy.

    Problems: - planning takes time
    - world changes unexpectedly
    - sensor errors break plans

    Example: Robot plans path → chair moves → plan fails.

    The robot must re-plan again and again.

    This makes it slow.

    Why Some People Disliked It¶

    Users: - too slow in real environments

    Control engineers: - not closed-loop enough

    AI researchers: - too monolithic and rigid

    Key Idea¶

    Hierarchical paradigm assumes: "If the robot thinks enough, it will act correctly."

    But real environments are dynamic.

    This leads to a big question:

    What if the robot stops planning so much
    and just reacts?

    That question leads to the next paradigm.

    Reactive Paradigm¶

    We just saw that the hierarchical paradigm
    plans a lot before acting.

    But real environments change quickly.

    People noticed: - robots were too slow
    - plans became outdated
    - unexpected obstacles broke plans

    So researchers asked:

    "What if robots stop overthinking
    and simply react to the world?"

    This idea led to the Reactive Paradigm.

    Core Idea¶

    The world is its own best model.

    Instead of building a big internal map,
    the robot directly reacts to sensor inputs.

    Sense → Act

    No heavy planning step.

    Key Principle¶

    Direct connection between perception and action.

    Sensors trigger actions immediately.

    Example: If obstacle detected → turn
    If path clear → move forward

    No long-term thinking required.

    Example¶

    Sensor Input → Immediate Action

    Example explanation:

    A wall-following robot:

    Wall appears → sensor detects → robot turns
    Path clears → robot moves forward
    Another object appears → robot turns again

    The robot only looks at current sensor values.

    Characteristics¶

    • No global map
    • No long-term memory
    • No complex planning
    • Tight coupling of sensing and action
    • Focus on real-time response

    Each behavior works independently.

    Biological Inspiration¶

    Many animals behave this way.

    Example: An insect avoids obstacles
    without building a map of the world.

    Reactive robotics takes inspiration
    from such biological systems.

    Strengths¶

    • Very fast responses
    • Works well in dynamic environments
    • Simple to implement
    • Robust to sudden changes

    Robots do not waste time planning.

    Limitations¶

    No big-picture thinking.

    Problems include: - local minima (getting stuck)
    - wandering without direction
    - no memory of past mistakes

    Example: Robot stuck in a corner
    keeps turning randomly.

    Sometimes random motion is used
    to escape traps.

    Why People Reacted to It¶

    Users: - liked it because it worked in real time

    AI researchers: - liked it but wanted planning back

    Control engineers: - disliked lack of formal guarantees

    Key Idea¶

    Reactive paradigm assumes: "Fast reaction is better than deep planning."

    But now another question appears:

    What if we want both? - global planning
    AND
    - fast reactions?

    That leads to the next paradigm.

    Hybrid Deliberative / Reactive Paradigm¶

    We have seen two extremes:

    Hierarchical paradigm: - smart planning
    - but slow and fragile in dynamic worlds

    Reactive paradigm: - fast and robust
    - but lacks long-term direction

    So researchers asked:

    "Why not combine both?"

    Use planning for direction,
    and reactions for safety.

    This idea led to the Hybrid Paradigm.

    Core Idea¶

    Think globally, act locally.

    The robot: - plans at a high level
    - reacts at a low level

    Both systems work together.

    How It Works¶

    Two main layers:

    1) Planning Layer (Deliberative) - builds maps
    - sets goals
    - computes paths
    - decides where to go

    Answers: "Where should I go?"

    2) Reactive Layer - reads sensors continuously
    - avoids obstacles
    - handles surprises
    - ensures safety

    Answers: "What should I do right now?"

    Example¶

    Planner → Goal Direction
    Reactive → Immediate Safety

    Example explanation:

    Task: Go from lab to office.

    Planner: Lab → corridor → stairs → office

    While moving: A chair appears

    Reactive layer: Turn immediately to avoid

    After avoidance: Control returns to planner

    Robot continues toward office.

    Simple Rule¶

    Planner gives purpose.
    Reactive layer ensures survival.

    One thinks long-term.
    One acts short-term.

    Local vs Global Models¶

    Hybrid systems use both:

    Global model: - maps
    - mission goals
    - long-term route

    Local model: - current obstacles
    - nearby people
    - immediate surroundings

    Both are necessary for good performance.

    Advantages¶

    • Practical in real environments
    • Balances intelligence and speed
    • Modular design
    • Asynchronous processing

    Planner can compute next goals
    while robot reacts to obstacles.

    Why People Liked It¶

    Users: - liked it because it worked reliably

    AI researchers: - liked the planning component

    Control engineers: - accepted it due to closed-loop behavior

    It satisfied many groups.

    Key Idea¶

    Hybrid paradigm assumes:

    "Plan for direction, react for safety."

    This is how many modern robots operate today.

    Local vs Global Models in Robotics¶

    In the hybrid paradigm we said:

    • Planner thinks globally
    • Reactive layer acts locally

    But what does "local" and "global" actually mean?

    Why does a robot need both?

    To answer this, we discuss
    local and global models.

    Global Model¶

    A global model is the robot’s
    big-picture understanding of the world.

    It includes: - maps
    - known locations
    - mission goals
    - planned routes

    It helps the robot decide
    long-term direction.

    Example¶

    Write:

    Global Model = Map + Goal + Route

    Example:

    A robot knows: - where the lab is
    - where the office is
    - which corridor connects them

    So it plans: Lab → Corridor → Office

    This is global thinking.

    Local Model¶

    A local model is the robot’s
    immediate understanding of its surroundings.

    It includes: - nearby obstacles
    - moving people
    - sudden changes
    - current sensor readings

    It helps the robot act safely
    right now.

    Example¶

    Local Model = Current Sensors

    Example:

    While moving to office: A person walks in front.

    Local model detects person
    → robot slows down or turns.

    This is local control.

    Why Global Alone Is Not Enough¶

    If robot only uses global model: - it may ignore sudden obstacles
    - it may collide with people
    - map may be outdated

    Global planning assumes
    the world stays the same.

    But real world changes.

    Why Local Alone Is Not Enough¶

    If robot only reacts locally: - it has no long-term goal
    - it may wander randomly
    - it may never reach destination

    Reactive robots survive
    but may not achieve missions.

    Balanced Approach¶

    Good robots combine both.

    Global model: - decides where to go

    Local model: - decides how to move safely

    Together they provide: - direction
    - safety
    - adaptability

    Key Idea¶

    Global = Purpose
    Local = Safety

    A successful robot needs both
    to perform well in real environments.

    How Robots Work: Robot Subsystems¶

    So far we discussed: - how robots think (paradigms)
    - how they plan and react
    - how they use local and global models

    Now a practical question:

    What actually makes a robot work?

    A robot is not just intelligence.
    It is a combination of subsystems
    working together.

    Core Robot Subsystems¶

    A robot typically has:

    • Sense (Perception/Recognition)
    • Plan (Control/Decision)
    • Act (Motion/Manipulation)
    • Power
    • Communication

    Each subsystem has a role.

    1) Sense (Perception)¶

    This subsystem gathers information
    from the environment.

    It answers: "What is happening around me?"

    Examples: - camera
    - LIDAR
    - ultrasonic sensors
    - GPS
    - IMU

    Without sensing: The robot is blind.

    Example¶

    World → Sensors → Robot

    Example explanation:

    A robot vacuum detects: - walls
    - furniture
    - stairs

    This data allows safe movement.

    2) Plan (Control/Decision)¶

    This subsystem processes information
    and decides actions.

    It answers: "What should I do next?"

    Examples: - path planning
    - obstacle avoidance decisions
    - task scheduling

    Planning turns data into decisions.

    Example¶

    Sensor Data → Decision → Command

    Example:

    If obstacle detected
    → decide to turn.

    3) Act (Motion/Manipulation)¶

    This subsystem executes actions
    in the real world.

    Examples: - wheels moving
    - robotic arms lifting
    - grippers holding objects

    It answers: "How do I perform the action?"

    Example¶

    Command → Motors → Movement

    Example:

    Robot arm receives command
    → motors rotate
    → object is picked.

    4) Power¶

    Robots need energy to operate.

    Examples: - batteries
    - wired power supply
    - solar power

    Without power: Nothing works.

    Power limits: - operation time
    - motor strength
    - computation ability

    5) Communication¶

    Allows robots to send and receive data.

    Examples: - Wi-Fi
    - Bluetooth
    - radio signals
    - wired networks

    Used for: - remote control
    - cloud processing
    - multi-robot coordination

    Putting It All Together¶

    All subsystems work in a loop:

    Sense → Plan → Act
    ↑ ↓
    Power & Communication support all

    If one subsystem fails,
    robot performance drops.

    Key Idea¶

    A robot is a system-of-systems.

    Good robotics requires: - good sensors
    - smart planning
    - reliable actuation
    - stable power
    - effective communication

    Sensors in Robotics¶

    We said robots must sense the world.

    But how do they actually do that?

    Robots cannot see, hear, or feel like humans.
    They rely on sensors.

    Sensors are the robot’s connection
    to the real world.

    Without sensors: - no awareness
    - no safe navigation
    - no intelligent behavior

    What is a Sensor?¶

    A sensor is a device that detects
    physical properties of the environment
    and converts them into signals
    a robot can process.

    Sensors measure things like: - distance
    - light
    - temperature
    - motion
    - position

    Active vs Passive Sensors¶

    This is a key classification.

    Active Sensors¶

    Active sensors send out energy
    and measure the response.

    They emit signals like: - sound waves
    - infrared light
    - laser pulses

    Then they measure the reflection.

    Example Logic¶

    Send signal → hit object → return signal → compute distance

    Why They Are Useful¶

    • Work in darkness
    • Give direct distance info
    • Less dependent on lighting

    Why They Are Not Always Ideal¶

    • Consume more power
    • Can be affected by interference
    • Sometimes limited range

    Passive Sensors¶

    Passive sensors do NOT emit energy.
    They only detect energy from environment.

    Examples: - cameras
    - microphones
    - light sensors

    Why They Are Useful¶

    • Low power consumption
    • Rich environmental information
    • Natural sensing

    Why They Are Not Always Ideal¶

    • Depend on lighting or conditions
    • Harder to estimate distance directly
    • Sensitive to noise

    1) Ultrasonic Sensor¶

    Type: Active

    How It Works¶

    • Sends ultrasonic sound waves
    • Measures echo return time
    • Calculates distance

    Example¶

    Send sound → Echo returns → Distance

    Good Because¶

    • Cheap
    • Simple
    • Works in dark
    • Good for obstacle detection

    Not Ideal Because¶

    • Low resolution
    • Wide beam (less precise)
    • Soft materials absorb sound

    Example issue: Curtains may not reflect well.

    2) Infrared (IR) Sensor¶

    Type: Active (usually)

    How It Works¶

    • Emits infrared light
    • Measures reflected light

    Good Because¶

    • Small and low-cost
    • Good for short distances
    • Fast response

    Used in: - line-following robots
    - proximity detection

    Not Ideal Because¶

    • Sensitive to sunlight
    • Affected by surface color
    • Limited range

    Example issue: Black surfaces absorb IR.

    3) LiDAR¶

    Type: Active

    How It Works¶

    • Sends laser pulses
    • Measures return time
    • Builds precise distance map

    Example¶

    Laser pulse → Reflection → 3D Map

    Good Because¶

    • Very accurate
    • High resolution
    • Creates maps
    • Great for navigation

    Used in: - self-driving cars
    - mapping robots
    - SLAM systems

    Not Ideal Because¶

    • Expensive
    • Higher power use
    • Can struggle in rain/fog

    Quick Comparison¶

    Sensor Accuracy Cost Range Notes
    Ultrasonic Medium Low Medium Simple obstacle detection
    IR Low-Medium Very Low Short Sensitive to surfaces
    LiDAR Very High High Long Mapping and navigation

    Summary of Sensors¶

    Sensors are critical because they: - provide environmental awareness
    - enable safe movement
    - support planning and control

    No single sensor is perfect.

    Good robots often use: multiple sensors together (sensor fusion)

    Example: Camera + LiDAR + IMU
    → more reliable perception

    Key Idea¶

    Better sensing leads to: - better decisions
    - safer robots
    - smarter behavior

    A robot is only as good as the information it receives.

    Scenarios¶

    Scenario 1 — The “Smart” Tour Guide Robot¶

    A museum robot: - has a full map of the building
    - plans routes between exhibits
    - BUT if a child steps in front, it immediately stops or turns

    Question¶

    Which paradigm BEST describes this robot?

    A) Reactive
    B) Hierarchical/Deliberative
    C) Hybrid

    Correct Answer¶

    C) Hybrid

    Why¶

    • Uses global map → deliberative component
    • Reacts instantly to people → reactive component
    • Combines planning + reaction

    Why NOT Others¶

    Reactive: - No map or planning

    Hierarchical: - Would stop and re-plan fully instead of quick avoidance

    Scenario 2 — The Overconfident Planner¶

    A robot in a warehouse: - builds a perfect map
    - computes full path
    - follows it strictly even when obstacles appear
    - frequently stops to re-plan

    Question¶

    Which paradigm is this?

    A) Reactive
    B) Hierarchical
    C) Hybrid

    Correct Answer¶

    B) Hierarchical

    Why¶

    • Heavy reliance on planning
    • Strong world model
    • Stops to re-plan

    Why NOT Others¶

    Reactive: - Would not build map

    Hybrid: - Would avoid locally without constant re-planning

    Scenario 3 — The Wandering Robot¶

    A robot: - moves using proximity sensors
    - turns when near obstacles
    - has no map
    - sometimes loops forever

    Question¶

    Which paradigm?

    A) Reactive
    B) Hierarchical
    C) Hybrid

    Correct Answer¶

    A) Reactive

    Why¶

    • Pure sensor-action link
    • No memory
    • No planning

    Why NOT Others¶

    Hierarchical: - Needs global model

    Hybrid: - Would include goal direction

    Scenario 4 — The Night Patrol Robot¶

    A robot patrols at night.
    Engineer must choose sensor for obstacle detection.

    Question¶

    Best sensor?

    A) Camera
    B) LiDAR
    C) Microphone

    Correct Answer¶

    B) LiDAR

    Why¶

    • Active sensor
    • Works in darkness
    • Gives distance

    Why NOT Others¶

    Camera: - Passive, needs light

    Microphone: - Not for obstacle distance

    Scenario 5 — The Energy-Limited Robot¶

    A small robot: - must save power
    - only needs general scene understanding
    - operates in well-lit area

    Question¶

    Best sensor?

    A) LiDAR
    B) Ultrasonic
    C) Camera

    Correct Answer¶

    C) Camera

    Why¶

    • Passive sensor
    • Low power
    • Rich visual info

    Why NOT Others¶

    LiDAR: - High power use

    Ultrasonic: - Limited scene info

    Scenario 6 — The Delivery Drone¶

    A drone: - plans route using GPS
    - avoids birds instantly using sensors
    - resumes route after avoidance

    Question¶

    Which paradigm?

    A) Reactive
    B) Hierarchical
    C) Hybrid

    Correct Answer¶

    C) Hybrid

    Why¶

    Planning + reactive avoidance.

    Why NOT Others¶

    Reactive: - No route planning

    Hierarchical: - Would re-plan fully each time
