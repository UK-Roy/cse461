    Chapter 5: Robot with Brain¶

    This chapter introduces the idea of giving a robot a “brain.” In robotics, the brain is not a biological brain. It is a computational system that receives information from sensors, processes that information, and makes decisions.

    A simple robot brain can be imagined as:

    Information → Processing → Decision

    For example, a robot may receive an image from a camera, distance from an ultrasonic sensor, or obstacle information from LiDAR. Then it processes that information and decides whether to move forward, stop, turn, classify an object, or avoid an obstacle.

    5.1 Robot with Brain¶

    A robot becomes intelligent when it can use information from the environment to make decisions.

    Examples of robot inputs:

    • Camera image
    • Distance sensor value
    • Temperature sensor value
    • Pressure sensor value
    • Sound sensor value
    • IMU data
    • LiDAR scan

    Examples of robot decisions:

    • Move forward
    • Stop
    • Turn left
    • Turn right
    • Detect a human
    • Avoid an obstacle
    • Classify an object

    So, the goal is to build a system that can transform sensor information into useful decisions.

    5.2 Inspiration from the Human Brain¶

    Artificial neural networks are inspired by the human brain.

    In the human brain:

    • Neurons receive signals.
    • Neurons process signals.
    • Neurons are connected to other neurons.
    • Learning happens by changing the strength of these connections.

    In artificial neural networks:

    • Inputs are the signals.
    • Weights are the connection strengths.
    • The output is the decision or prediction.

    A simplified idea is:

    Inputs → Artificial Neuron → Output

    5.3 Artificial Neuron¶

    An artificial neuron is the basic unit of a neural network. It receives input values, multiplies each input by a weight, and then adds the results.

    Suppose we have three inputs:

    x1, x2, x3

    Each input has a corresponding weight:

    w1, w2, w3

    The neuron output is:

    y = w1x1 + w2x2 + w3x3

    For n inputs, the general formula is:

    y = w1x1 + w2x2 + ... + wnxn

    or:

    Neuron Output = Σ wi xi

    where:

    • xi = input feature
    • wi = weight
    • y = output

    5.4 What is a Feature?¶

    A feature is an input variable used by a machine learning model.

    Example:

    A robot wants to decide whether an object is dangerous. It may use these features:

    • Object size
    • Object distance
    • Object speed

    Then the model may calculate:

    Danger Score = w1(size) + w2(distance) + w3(speed)

    Here, size, distance, and speed are features.

    5.5 What is a Weight?¶

    A weight tells how important a feature is.

    If a feature has a large weight, it has a strong effect on the output. If a feature has a small weight, it has a weak effect on the output.

    Example:

    y = 0.9 × Tumor Size + 0.1 × Age

    Here, tumor size has more importance because its weight is larger.

    If the equation becomes:

    y = 0.2 × Tumor Size + 0.8 × Age

    then age has more importance.

    5.6 Bias and Activation Function¶

    In practical neural networks, two additional components are commonly used: bias and activation function.

    Bias¶

    Bias is an extra value added to the neuron output.

    y = w1x1 + w2x2 + ... + wnxn + b

    Bias helps shift the output. It works like a threshold.

    Activation Function¶

    An activation function is applied after the weighted sum. It helps the neural network learn non-linear patterns.

    Common activation functions:

    • ReLU
    • Sigmoid
    • Tanh

    For this course, we can first understand the simple linear model:

    y = Σ wi xi

    5.7 Machine Learning¶

    Machine learning is the process where a computer or robot learns patterns from data instead of being explicitly programmed for every situation.

    In traditional programming:

    Rules + Data → Output

    In machine learning:

    Data + Output → Learned Rules

    Example:

    Instead of manually writing all rules to detect cats, dogs, or humans in images, we give the machine many examples. The machine learns patterns from those examples.

    5.8 Why Do We Need Learning?¶

    In robotics, it is very difficult to manually write rules for every possible situation.

    A robot may face:

    • Different lighting conditions
    • Different object shapes
    • Different floor conditions
    • Different human behavior
    • Different obstacle positions
    • Different camera angles

    Writing fixed rules for all these cases is almost impossible.

    Therefore, robots need learning.

    In robotics and machine learning, the process of finding good weights from data is called training.

    5.9 Types of Learning¶

    There are four common types of learning:

    1. Supervised learning
    2. Unsupervised learning
    3. Semi-supervised learning
    4. Reinforcement learning

    5.10 Supervised Learning¶

    In supervised learning, the model learns from labeled data.

    Each example contains:

    Input → Correct Output

    Example:

    Tumor Size Condition
    10 Malignant
    2 Benign
    1 Benign
    5 Malignant

    Here:

    • Input = tumor size
    • Output label = condition

    Robotics example:

    Sensor/Input Data Label
    Image of obstacle Obstacle
    Image of free road Free path
    Image of human Human

    The robot learns using the labeled examples.

    5.11 Unsupervised Learning¶

    In unsupervised learning, the data does not have labels.

    The model tries to find hidden patterns or groups by itself.

    Example:

    A robot collects images of different objects, but nobody tells the robot the object names. The model may group similar objects together based on shape, color, or size.

    Robotics example:

    Unknown objects → Group similar objects → Cluster 1, Cluster 2, Cluster 3

    5.12 Semi-supervised Learning¶

    Semi-supervised learning uses both labeled and unlabeled data.

    Usually, it uses:

    • A small amount of labeled data
    • A large amount of unlabeled data

    Example:

    A robot has:

    100 labeled images
10,000 unlabeled images

    It uses both types of data to improve learning.

    This is useful because labeling data can be expensive and time-consuming.

    5.13 Reinforcement Learning¶

    In reinforcement learning, an agent learns by interacting with an environment.

    The agent receives:

    • Reward for good actions
    • Penalty for bad actions

    Example:

    A robot learns to walk.

    • If it moves forward without falling, it receives a reward.
    • If it falls, it receives a penalty.

    The goal is to maximize total reward over time.

    5.14 Difference Between Learning Types¶

    Type Data Main Idea Robotics Example
    Supervised Learning Labeled data Learn input-output mapping Classify obstacle vs free path
    Unsupervised Learning Unlabeled data Find hidden patterns Group unknown objects
    Semi-supervised Learning Few labels + many unlabeled samples Use both labeled and unlabeled data Learn from limited robot labels
    Reinforcement Learning Interaction + reward Learn actions Robot learns navigation or walking

    5.15 Classification and Regression¶

    Machine learning problems are commonly divided into two types:

    1. Classification
    2. Regression

    5.16 Classification¶

    Classification means predicting a category or class.

    The output is discrete.

    Examples:

    • Cat or dog
    • Benign or malignant
    • Obstacle or free path
    • Human or non-human

    Robotics example:

    A robot camera sees an object and predicts:

    Chair / Table / Human / Door

    5.17 Regression¶

    Regression means predicting a continuous numerical value.

    Examples:

    • Predicting temperature
    • Predicting distance
    • Predicting speed
    • Predicting price

    Robotics example:

    A robot predicts the distance to an obstacle:

    Distance = 2.5 meters

    5.18 Classification vs Regression¶

    Aspect Classification Regression
    Output Category Continuous number
    Example output Cat, dog, human 2.5 m, 25°C, 1000 taka
    Robotics example Obstacle type detection Distance prediction
    Common metric Accuracy, precision, recall MSE, RMSE, MAE

    5.19 Weighted Sum Example¶

    Suppose we have two features:

    x1 = Tumor Size
x2 = Age

    Suppose the weights are:

    w1 = 0.9
w2 = 0.1

    For a patient:

    Tumor Size = 10
Age = 50

    The output score is:

    y = 0.9 × 10 + 0.1 × 50
  = 9 + 5
  = 14

    Another patient:

    Tumor Size = 2
Age = 30

    y = 0.9 × 2 + 0.1 × 30
  = 1.8 + 3
  = 4.8

    The model can use this score to classify the condition.

    5.20 Example: Features and Output¶

    Consider the following house price dataset:

    Size (sq-ft) Bedroom Kitchen Main Road Balcony Price
    1600 4 1 0.2 2 20000
    1400 3 1 0.5 1 12000
    1600 2 1 0.2 2 10000
    2000 4 2 0.1 3 43000

    Features:

    Size, Bedroom, Kitchen, Main Road, Balcony

    Output:

    Price

    This is a regression problem because the output is a continuous numerical value.

    5.21 How Many Weights Are There?¶

    If one neuron has n inputs, then it has n weights.

    Example:

    Inputs: x1, x2, x3
Weights: w1, w2, w3

    So, 3 inputs require 3 weights.

    If there are 10 inputs, the neuron has 10 weights.

    5.22 Counting Weights in a Neural Network¶

    In a fully connected neural network, every neuron in one layer connects to every neuron in the next layer.

    The number of weights between two layers is:

    Number of weights = neurons in current layer × neurons in next layer

    Example network:

    Input layer = 3 neurons
Hidden layer 1 = 4 neurons
Hidden layer 2 = 4 neurons
Output layer = 1 neuron

    Weights from input to hidden layer 1:

    3 × 4 = 12

    Weights from hidden layer 1 to hidden layer 2:

    4 × 4 = 16

    Weights from hidden layer 2 to output:

    4 × 1 = 4

    Total weights:

    12 + 16 + 4 = 32

    5.23 Images as Input¶

    Robots often use cameras. A camera image is made of pixels.

    A grayscale image can be represented as a 2D matrix.

    Example:

    1 1 0
4 2 1
0 2 1

    Each number represents the intensity of a pixel.

    5.24 Flattening¶

    Flattening means converting a 2D matrix into a single vector.

    Example image matrix:

    1 1 0
4 2 1
0 2 1

    Flattened vector:

    [1, 1, 0, 4, 2, 1, 0, 2, 1]

    So a 3 × 3 image becomes 9 input features.

    5.25 Why Do We Flatten?¶

    A basic neural network usually accepts input as a vector.

    But an image is normally a 2D or 3D matrix.

    Therefore, we flatten the image so that it can be passed into a basic neural network.

    Image → Matrix → Flattened vector → Neural network

    5.26 Problems with Flattening¶

    Flattening has two major problems.

    Problem 1: Too Many Features¶

    Small image:

    3 × 3 = 9 features

    Larger image:

    12 × 12 = 144 features

    Real image:

    680 × 420 = 285,600 features

    RGB image:

    680 × 420 × 3 = 856,800 features

    This creates huge computation.

    Problem 2: Loss of Spatial Structure¶

    Images have spatial relationships.

    Nearby pixels may form:

    • Edges
    • Corners
    • Shapes
    • Textures
    • Object boundaries

    When we flatten an image, the model loses the 2D structure and nearby pixel relationships.

    This is bad for robots because robots need to understand object shapes, obstacles, road boundaries, and human positions.

    5.27 Convolution¶

    Convolution solves many problems of flattening.

    Instead of looking at the whole image at once, convolution looks at small local regions.

    A small matrix called a kernel or filter slides over the image.

    The filter can extract features such as:

    • Edges
    • Textures
    • Shapes

    This is very useful for robot vision.

    5.28 Kernel or Filter¶

    A kernel is a small matrix used in convolution.

    Example kernel:

    1 0 1
0 1 0
1 0 1

    The kernel slides over the input image. At each position, it multiplies with the image patch and sums the result.

    5.29 Convolution Operation Example¶

    Input image patch:

    1 1 1
0 1 1
0 0 1

    Kernel:

    1 0 1
0 1 0
1 0 1

    Multiply matching cells and add:

    Output = (1×1) + (1×0) + (1×1)
       + (0×0) + (1×1) + (1×0)
       + (0×1) + (0×0) + (1×1)

    Output = 1 + 0 + 1 + 0 + 1 + 0 + 0 + 0 + 1
Output = 4

    This value becomes one cell in the feature map.

    5.30 Feature Map¶

    A feature map is the output produced after applying a convolution filter over an image.

    If a filter detects edges, the feature map shows where edges appear in the image.

    Example:

    Image + Edge Filter → Edge Feature Map

    5.31 Benefits of Convolution¶

    Convolution is useful because it:

    • Preserves spatial relationships
    • Reduces the number of parameters
    • Extracts meaningful image features
    • Works well for robot vision
    • Helps detect objects, edges, textures, and shapes

    5.32 Pooling Operation¶

    Pooling reduces the size of a feature map.

    It is also called:

    • Subsampling
    • Downsampling

    Pooling helps reduce computation while keeping important information.

    Two common types are:

    1. Max pooling
    2. Average pooling

    5.33 Max Pooling¶

    Max pooling takes the maximum value from a small region.

    Example:

    12 20
8  30

    Max pooling output:

    30

    5.34 Average Pooling¶

    Average pooling takes the average value from a small region.

    Example:

    12 20
8  30

    Average pooling output:

    (12 + 20 + 8 + 30) / 4 = 17.5

    5.35 Stride¶

    Stride defines how many pixels the filter moves after each convolution operation.

    If stride is 1, the filter moves one pixel at a time.

    If stride is 2, the filter moves two pixels at a time.

    Stride = 1 → larger output feature map
Stride = 2 → smaller output feature map

    5.36 Padding¶

    Padding means adding extra pixels around the border of an image before applying convolution.

    Usually, zeros are added.

    Padding is used to:

    • Control output size
    • Preserve edge information
    • Prevent the image from shrinking too quickly

    Example:

    Original image:

    1 2 3
4 5 6
7 8 9

    After zero padding:

    0 0 0 0 0
0 1 2 3 0
0 4 5 6 0
0 7 8 9 0
0 0 0 0 0

    5.37 Output Dimension After Convolution¶

    For one dimension, the output size is:

    Wout = ((W - F + 2P) / S) + 1

    where:

    • W = input width
    • F = filter size
    • P = padding
    • S = stride

    Example:

    W = 5
F = 3
P = 0
S = 1

    Wout = ((5 - 3 + 2×0) / 1) + 1
Wout = 3

    So a 5 × 5 input with a 3 × 3 filter, no padding, and stride 1 gives a 3 × 3 output.

    5.38 Convolutional Neural Network (CNN)¶

    A Convolutional Neural Network, or CNN, is a neural network designed for image data.

    A typical CNN structure is:

    Input Image
→ Convolution
→ ReLU
→ Pooling
→ Convolution
→ ReLU
→ Pooling
→ Flatten
→ Fully Connected Layer
→ Output

    CNNs are very useful in robotics for:

    • Object classification
    • Object localization
    • Object detection
    • Lane detection
    • Human detection
    • Obstacle recognition

    5.39 Classification, Localization, and Object Detection¶

    Classification¶

    The model predicts what object is in the image.

    Example:

    Cat

    Classification + Localization¶

    The model predicts the object class and draws a box around it.

    Example:

    Cat + bounding box

    Object Detection¶

    The model detects multiple objects and draws bounding boxes around each object.

    Example:

    Cat, dog, duck

    5.40 Network Types Summary¶

    Network Type Common Use
    CNN Images
    RNN Time series
    LSTM Long sequences
    Reinforcement Learning Decision making
    Transformer Language, sequence modeling, vision-language systems

    Large Language Models such as GPT are based on transformer networks.

    Conceptual Questions¶

    Q1. What is machine learning?¶

    Machine learning is a method that allows computers or robots to learn patterns from data and make decisions without being explicitly programmed for every case.

    Q2. What is an artificial neuron?¶

    An artificial neuron is a computational unit that takes inputs, multiplies them by weights, adds them, and produces an output.

    Q3. What is a feature?¶

    A feature is an input variable used by a machine learning model.

    Q4. What is a weight?¶

    A weight controls the importance of a feature in the model output.

    Q5. Why do we need training?¶

    Training is needed because manually choosing weights is almost impossible for real neural networks.

    Q6. What is the difference between supervised and unsupervised learning?¶

    Supervised learning uses labeled data. Unsupervised learning uses unlabeled data and tries to find hidden patterns.

    Q7. What is reinforcement learning?¶

    Reinforcement learning is a learning method where an agent learns by taking actions and receiving rewards or penalties.

    Q8. What is the difference between classification and regression?¶

    Classification predicts a category. Regression predicts a continuous numerical value.

    Q9. Why do we flatten an image?¶

    We flatten an image to convert a matrix into a vector so that it can be used as input to a basic neural network.

    Q10. What are the problems with flattening?¶

    Flattening creates too many features and loses spatial relationships between nearby pixels.

    Q11. Why is losing spatial structure bad for robot vision?¶

    Because robots need to understand edges, shapes, objects, and obstacles. These depend on relationships between nearby pixels.

    Q12. What is convolution?¶

    Convolution is an operation where a small filter slides over an image to extract features such as edges, textures, and shapes.

    Q13. What is a feature map?¶

    A feature map is the output of a convolution operation. It shows where certain features appear in the image.

    Q14. What is pooling?¶

    Pooling reduces the size of a feature map while keeping important information.

    Q15. What is stride?¶

    Stride is the number of pixels a filter moves after each convolution operation.

    Q16. What is padding?¶

    Padding means adding extra pixels around the border of an image before applying convolution.

    Q17. Why are CNNs useful for robots?¶

    CNNs are useful because robots often use camera images, and CNNs can extract visual features from images.

    Math Practice Questions¶

    Q1. A neuron has 5 inputs. How many weights does it have?¶

    5 weights

    Q2. A neuron has 8 inputs. How many weights does it have?¶

    8 weights

    Q3. A network has 4 input neurons and 3 hidden neurons. How many weights are between these two layers?¶

    4 × 3 = 12 weights

    Q4. A network has 6 input neurons, 4 hidden neurons, and 2 output neurons. Find the total number of weights.¶

    Input to hidden = 6 × 4 = 24
Hidden to output = 4 × 2 = 8
Total = 24 + 8 = 32

    Q5. A network has 3 input neurons, 5 neurons in hidden layer 1, 4 neurons in hidden layer 2, and 1 output neuron. Find the total number of weights.¶

    Input to hidden 1 = 3 × 5 = 15
Hidden 1 to hidden 2 = 5 × 4 = 20
Hidden 2 to output = 4 × 1 = 4
Total = 15 + 20 + 4 = 39

    Q6. A grayscale image has size 12 × 12. How many features will it have after flattening?¶

    12 × 12 = 144 features

    Q7. An RGB image has size 100 × 100 × 3. How many features will it have after flattening?¶

    100 × 100 × 3 = 30,000 features

    Q8. Find the output dimension for convolution: W = 7, F = 3, P = 0, S = 1.¶

    Wout = ((W - F + 2P) / S) + 1
Wout = ((7 - 3 + 0) / 1) + 1
Wout = 5

    Q9. Find the output dimension for convolution: W = 10, F = 3, P = 1, S = 1.¶

    Wout = ((10 - 3 + 2×1) / 1) + 1
Wout = 10

    Q10. Find the output dimension for convolution: W = 8, F = 2, P = 0, S = 2.¶

    Wout = ((8 - 2 + 0) / 2) + 1
Wout = 4

    Q11. A 28 × 28 grayscale image is flattened. How many input features are produced?¶

    28 × 28 = 784 features

    Q12. A 64 × 64 RGB image is flattened. How many input features are produced?¶

    64 × 64 × 3 = 12,288 features
